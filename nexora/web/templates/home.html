Set up in a few minutes

  1. Run install.bat

    It installs Python packages and creates your settings file.

  2. Paste your bot token

    Create an application in the Discord Developer Portal and copy its token and OAuth details into .env.

  3. Run start.bat and log in

    The bot and this website start together. Log in with Discord, pick a server and switch on the features you want.
