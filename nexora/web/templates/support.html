Slash commands don't show up

Global commands can take up to an hour the first time. Set DEV_GUILD_ID in .env for instant updates in one server, and make sure the bot was invited with the applications.commands scope (the invite button includes it).

"Discord refused that action"

Nexora's highest role must be above the member or role it's acting on. Go to Server Settings, then Roles, and drag Nexora up. The dashboard's Overview page also lists any permissions Nexora is missing.

Logs show "content unavailable"

Discord doesn't send old message content to bots. Nexora can only show the content of messages it saw while it was running. Turn on the Message Content intent in the Developer Portal.

Login loops or "Discord rejected the login"

The redirect URL in the Developer Portal must match DISCORD_REDIRECT_URI exactly, including http versus https and the port.

Something else

Bot owners can open the System page to see recent errors with full details. Include those when asking for help.
