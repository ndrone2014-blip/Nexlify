Privacy Policy

Last updated October 31, 2026. This explains what Nexora stores, why, and how to get it removed.

Who runs Nexora

Nexora is run by an independent developer, not by Discord. Questions about this policy go to the {% if config.support_url %}support server{% else %}support page{% endif %}.

What Nexora stores

Nexora only stores data for the features a server's staff turn on. Depending on those settings, that can include:

  • Discord IDs of users, servers, channels and roles, so features know who and where things belong to.
  • Server logs: when logging is on, the content and attachments of edited and deleted messages, plus member, role, voice and server changes. Logs are deleted automatically after the server's retention period (90 days by default).
  • Moderation records: warnings, cases, notes, appeals and automod flags, including the message that triggered them.
  • Tickets and applications: answers you submit, ticket transcripts and ratings.
  • Community features: levels and XP, economy balances, birthdays you set, reminders, suggestions, polls and giveaway entries.
  • Dashboard logins: your Discord ID, username, avatar and the list of servers you're in, plus a Discord login token kept on the server (never in your browser) for up to 7 days.
  • Error reports: technical details when something breaks, so it can be fixed.

Nexora reads message content only to run the features a server enables (logging, automod, leveling and custom commands). It doesn't sell data, show ads, or share data with anyone except as described below.

AI assistant

If a server turns on /ask, the question you type is sent to Anthropic to generate an answer. Don't include personal information in questions.

Who can see your data

Staff of a server can see that server's logs, moderation records, tickets and applications in Discord and on the dashboard. Leaderboards may be public if a server turns them on. The bot's operator can access the database to run and fix the bot.

Getting your data removed

Ask in the {% if config.support_url %}support server{% else %}support channel{% endif %} and include your Discord user ID. Your data will be deleted within 30 days, except records a server needs to keep for moderation (such as bans), which are removed when that server removes Nexora or asks for its data to be deleted. Server owners can also reset any feature from the dashboard.

Children

Nexora follows Discord's age requirements. If you're under the minimum age to use Discord in your country, don't use Nexora.

Changes

If this policy changes, the date at the top will change too. Continuing to use Nexora after a change means you accept it.
