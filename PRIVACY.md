# Privacy Policy

Effective October 31, 2026. This policy explains what information the Nexora Discord bot and its website and dashboard collect, why, how long it's kept, and how to get it deleted.

> **The short version**

- Nexora only stores what it needs to run the features a server's staff turn on.
- Nexora never sells your data, never shows ads, and never uses your data to train AI.
- Server staff can see their own server's logs, moderation records, tickets and applications.
- You can ask for your data to be deleted at any time through the Nexora support server.

## 1. Who we are

Nexora is an independent project developed by Drone Hive Studios (developer: @ndrone40). It is not made, endorsed or run by Discord. In this policy, "Nexora", "we" and "us" mean the bot, its website and dashboard, and the people who run it. "You" means anyone who uses Nexora, is in a server that uses Nexora, or visits the website.

Questions about privacy can be sent through the Nexora support server.

## 2. Information Nexora collects

What's collected depends on which features a server enables. A server that only uses a few features will have far less stored than one that uses everything.

### 2.1 Discord information

- **IDs:** the Discord IDs of users, servers, channels, roles and messages, so features know who and where things belong to.
- **Server details:** a server's name, icon, owner ID and member count.
- **Usernames and avatars**, which Nexora reads from Discord to show names in logs, leaderboards and the dashboard.

### 2.2 Message content

Nexora uses Discord's Message Content access only to run features a server turns on:

- **Logging:** the before and after text of edited messages, the text and attachment links of deleted messages, and member, role, channel, voice and server changes.
- **Automod:** messages are checked against the server's rules. When a message breaks a rule, its content is saved with the flag so staff can review it.
- **Leveling and stats:** Nexora counts messages to award XP and build activity charts. It stores the count, not the message.
- **Custom commands and automations:** messages are checked for the server's triggers and are not stored.

Messages that don't trigger one of these features are not saved.

### 2.3 Things you create or submit

- **Moderation:** warnings, cases, bans, timeouts, staff notes and the reasons given for them, and any appeals you write.
- **Tickets and applications:** your answers, ticket details, ratings and comments, plus staff votes and notes on applications.
- **Community features:** XP and levels, economy balances, items and achievements, birthdays you set (month and day only, never the year), reminders, suggestions, poll votes, giveaway entries and starboard posts.
- **Staff activity:** how many moderation actions each staff member takes per day, shown to that server's staff.

### 2.4 Dashboard and website

- **Logging in with Discord:** when you log in, Discord shares your user ID, username, display name, avatar and the list of servers you're in. Nexora only asks for the `identify` and `guilds` permissions. It can't see your email, messages or friends.
- **Login session:** your session, including the Discord login token, is stored on the server for up to 7 days. Your browser only holds a random session ID cookie.
- **Dashboard changes:** a record of which staff member changed which setting, so a server's staff can see who changed what.

### 2.5 Technical information

- **Error reports:** technical details when something breaks, sometimes including the server ID involved.
- **Usage counts:** how often each feature is used in a server, with no personal details.

## 3. How Nexora uses information

- To run the features each server enables, such as logging, moderation, tickets and leveling.
- To show server staff their server's records, settings and statistics in Discord and on the dashboard.
- To check that you're allowed to manage a server before letting you change it on the dashboard.
- To keep Nexora secure, stop abuse, and fix bugs.

Nexora does not sell or rent data, use it for advertising, build profiles of people across servers, or use it to train AI models.

## 4. Cookies

The website uses two small cookies, both needed for logging in:

- `nx_session` keeps you logged in for up to 7 days.
- `nx_oauth` protects the login process and is deleted after 10 minutes or once you've logged in.

There are no tracking, analytics or advertising cookies.

## 5. Who information is shared with

- **Server staff** can see their server's logs, moderation records, tickets, applications, staff activity and dashboard changes.
- **Other members** can see things that are public by design, such as leaderboards, giveaway results and suggestions. A server can choose to make its leaderboard viewable on the website.
- **Discord** receives everything the bot does in Discord, as with any bot. See [Discord's Privacy Policy](https://discord.com/privacy).
- **Anthropic:** if a server turns on the `/ask` AI assistant, the question you type is sent to Anthropic to generate an answer. Only your question and the server's name are sent, not your username or ID. See [Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy). Don't put personal information in questions.
- **Hosting providers:** the public website is hosted on Netlify and loads fonts from Google Fonts, and the dashboard loads a chart library from Cloudflare's cdnjs. Like any website host, these services may see your IP address and browser details when you visit.
- **The law:** information may be shared if required by law, or to protect people's safety.

## 6. How long information is kept

- **Server logs:** deleted automatically after the server's retention period, 90 days by default. Server staff can change this.
- **Login sessions:** deleted when you log out or after 7 days.
- **Error reports and automation run history:** deleted after 30 days.
- **Everything else** (moderation records, tickets, levels, economy and so on) is kept while the server uses Nexora, so features keep working, until the server's staff reset it or deletion is requested.
- **Servers that remove Nexora:** the server's data is kept so its setup comes back if Nexora is added again. The server owner can ask for it to be deleted at any time.

## 7. Your choices and rights

- **Remove your own data:** you can remove your birthday and cancel your reminders with Nexora's commands.
- **Request a copy or deletion:** ask in the Nexora support server and include your Discord user ID. Requests are handled within 30 days. Records a server needs for safety, such as bans and moderation cases, may be kept until that server's owner agrees to delete them.
- **Server owners** can reset features and delete their server's data from the dashboard, or ask for all of it to be removed.
- **Opting out:** if you don't want Nexora to process your messages, you can leave servers that use it. Server staff decide which features are on in their server.

Depending on where you live, laws such as the GDPR or CCPA may give you extra rights, like correcting your data or objecting to how it's used. Contact the Nexora support server to use them.

## 8. Security

Nexora keeps login tokens on the server and out of your browser, uses secure cookies, protects dashboard actions against forged requests, rate-limits requests, and checks your Discord permissions before every dashboard change. No system is perfectly secure, but problems are fixed as quickly as possible. Found a security issue? Please report it privately through the Nexora support server.

## 9. Children

Nexora is not meant for anyone under 13, or under the minimum age to use Discord in their country. Nexora doesn't knowingly collect information from children under that age. If you think a child's information has been collected, contact the Nexora support server and it will be deleted.

This policy may be updated as Nexora changes. The date at the top shows when it last changed, and bigger changes will be announced in the Nexora support server. Using Nexora after a change means you accept the updated policy.
